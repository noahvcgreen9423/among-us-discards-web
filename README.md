## Overview

Among Us Discards is a small HTML page for tracking discards and writing down useful game information while playing Among Us. It keeps those notes accessible in the browser, without requiring a separate application or a complicated installation process.

The page is intended for players who need a quick reference during or after a match. Its lightweight design provides a focused place for recording observations, reminders, and other session details.

## Using the Page

Launch the page before a game or keep it open while playing. Use the available workspace to capture discards and update notes as the session develops.

A normal session can look like this:

1. Open the page in a web browser.
2. Add discards, observations, and other relevant notes.
3. Revise the entries as the round continues.
4. Consult the recorded information whenever you need a quick reminder.

When serving the files yourself, reload the browser after changing the HTML or any associated files.
